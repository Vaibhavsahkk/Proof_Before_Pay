# Submission Checklist

## Complete Solution Code and Changelog

- [ ] Intended user and bottleneck are clear in README.
- [ ] Agent instructions and deterministic tools are included.
- [ ] Every meaningful iteration has evidence and a decision.
- [ ] Removed experiments and lessons are documented.
- [ ] Main failure mode and hot take are included.

## Reproduction Guide

- [ ] Clean environment setup is documented.
- [ ] Exact baseline, agent, and evaluation commands are present.
- [ ] Required data and expected outputs are explained.
- [ ] Versions, runtime, and cost are recorded from observation.
- [ ] Independent clean-clone run reproduces the main result.

## Solution Video - Maximum 5 Minutes

- [ ] Problem and user bottleneck.
- [ ] Simple baseline.
- [ ] One realistic end-to-end execution.
- [ ] Final comparison and primary metric.
- [ ] Improvement changelog.
- [ ] Most valuable change and one removed experiment.
- [ ] Human decision boundary is visible.

## Agent Trajectories

- [ ] Representative trajectory for every agent used.
- [ ] Agent instruction, tool calls, tool responses, retries, and final result are readable.
- [ ] Feedback and human checkpoints are included.
- [ ] Traces are sanitized and contain no credentials or private data.

## Final Safety and Quality Gate

- [ ] No payment execution.
- [ ] No definitive fraud declaration.
- [ ] No private financial data.
- [ ] No credentials.
- [ ] Benchmark frozen before scoring.
- [ ] Baseline and agent evaluated fairly on identical cases.
- [ ] Every result claim links to evidence.
- [ ] External ChatGPT authorizes final submission.
