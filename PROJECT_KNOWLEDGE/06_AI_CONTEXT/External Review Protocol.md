# External Review Protocol

## Roles

- Antigravity executes approved repository work.
- Local ChatGPT monitors evidence, safety, and phase scope; it cannot approve a phase.
- External ChatGPT is the final phase gatekeeper.
- The human is final authority for secrets, permissions, paid services, external accounts, and consequential actions.

## Conversation Continuity

Use the original master-context conversation titled `Hackathon research prompt` for external phase audits. A shared conversation URL is a read-only snapshot and must not be treated as the writable audit destination. Do not use the separate `Phase 1 Audit Verification` conversation for the final gate decision.

## Gate Rule

Only the exact external verdict `PHASE APPROVED — 100%` unlocks the next hackathon phase. `PHASE FAIL` keeps the current phase locked. Phase 1 is approved; Phase 2 is ACTIVE in remediation; Phase 3+ is locked.

## Data Sharing Boundary

Share only project-related, sanitized evidence. Never send credentials, private financial data, or unrelated local files.
