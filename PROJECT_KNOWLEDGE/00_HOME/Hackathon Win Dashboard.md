## Win-Critical Rules

- Never tune ground truth to improve results.
- Never claim a result that was not observed.
- Freeze cases before baseline and agent scoring.
- Keep baseline and agent inputs/evaluation fair.
- Preserve failed and removed experiments in the changelog.
- Make the final output useful to an AP reviewer, not merely technically correct.
- Keep every consequential decision with a human.
- Use only synthetic/public/approved data and keep secrets out of code, logs, traces, evidence, and chat.
