If a claim is not supported by an attached source or actual executable evidence, mark it `UNVERIFIED`.

`PHASE APPROVED — 100%`

Then summarize the critical evidence.

`PHASE FAIL`

Then provide:
1. Blocking issues
2. Evidence
3. Exact fixes
