# PHASE RULES

Exactly one phase is active at a time.

Allowed transition:
Phase N -> Phase N+1 ONLY when all three conditions are true:
1. Antigravity completes every acceptance criterion with executable evidence.
2. Local ChatGPT marks `READY FOR EXTERNAL CHATGPT REVIEW`.
3. External ChatGPT returns the exact string `PHASE APPROVED — 100%`.

Otherwise:
- remain in the current phase
- fix blockers
- re-run affected verification
- regenerate the review packet

A failure cannot be bypassed by changing STATUS.md manually.
